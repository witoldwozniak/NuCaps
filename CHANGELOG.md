# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## What this file covers

This file covers the software: `NuCaps.Core` and `NuCaps.Cli`. It records what changed for someone who uses them.

The capability records and the schema are versioned separately, because they have their own lifecycle. Their changes do not belong here.

Changes to the repository itself do not appear here either. Continuous integration, documentation, and build configuration are all readable in the git history, and none of them change what a user can do.
